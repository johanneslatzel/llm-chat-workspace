# Overview

`llm-chat-workspace` provides workspace and path-access management for the `llm-chat` ecosystem. It is the shared workspace layer used by [`llm-chat-file`](https://github.com/johanneslatzel/llm-chat-file) and [`llm-chat-shell`](https://github.com/johanneslatzel/llm-chat-shell).
